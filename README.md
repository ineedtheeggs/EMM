# EMM

A repo for Electricity market modelling projects that interest me.

## Projects

### Energy Forecasting

To forecast electricity prices; it is a class with objects to access information from [SMARD through an API]([url](https://smard.api.bund.dev)). 
It also contains functions to forecast prices using ARIMA techniques on the time series data. 
The models are based on this paper: [Xie et. al. (2013)]([url](https://doi.org/10.1109/EEM.2013.6607293))
The methodology, results and current scope of current work is elucidated in this [doc file]([url](https://docs.google.com/document/d/1IrDfbz86o9bCYzvZEnBYVugeJTbzRINooCXJwLSVtes/edit?usp=sharing)).
